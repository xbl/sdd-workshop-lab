# 限额活动报名练习 · 项目原则

## 先确认规格

用业务目标、规则、异常和可观察的验收用例写清需要支持的行为。有歧义时向讲师确认，并把答复写进规格。小组评审 `spec.md` 后再做技术方案和任务拆分。计划和任务应能追溯到已确认的规则。

## 沿用起始项目边界

继续使用现有的 `index.html`、`page.js` 和 `registration.js`，保留已有 `register(state, { userId, now })` 接口及页面使用的输出结构。两个视图共享内存状态，用顺序提交模拟页面显示过时的场景。练习全程在本地运行，无需后端、数据库或第三方包。

## 让验证可复现

运行行为测试时由调用方传入固定的 `now`，使用 Node.js 自带的测试工具即可。任务写清被验的规则、操作和可观察的结果。保留规格、任务和实际执行状态，供课堂回看。
